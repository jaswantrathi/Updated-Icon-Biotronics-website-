# ICON BIOTRONICS — Premium Website Build

This is a self-contained responsive static website prototype.

## Run locally
Open `index.html` directly in a browser, or run:
`python -m http.server 8080`

Then visit:
`http://localhost:8080`

## Deployment
Upload the contents to any static web host. For production:
- configure HTTPS
- point the domain to the host
- configure server security headers
- connect a real secure backend for form processing
- submit sitemap to Google Search Console
- verify business facts, certifications, testimonials and manufacturer authorizations before publication

## Important
The service form intentionally opens a pre-filled WhatsApp request rather than pretending there is a secure backend. Replace it with a secure server-side endpoint before collecting uploads or sensitive operational data.
